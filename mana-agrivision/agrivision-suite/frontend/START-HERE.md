# Start Here — Mana Polam

1. Read `README.md` for frontend setup and backend API connection details.
2. Read `REQUIREMENTS_STATUS.md` for implementation and verification boundaries.
3. Copy `.env.example` to `.env` and set `VITE_API_BASE_URL`.
4. Run `npm install`, then `npm run dev`.
5. Keep the FastAPI backend running and configure CORS for the Vite frontend origin.

This archive is frontend-only. It does not contain backend source code or credentials.
