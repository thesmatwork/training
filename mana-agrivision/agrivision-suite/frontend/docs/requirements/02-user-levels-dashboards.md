# 02. User Levels and Dashboards

## Beginner — green theme
**Goal:** help a new farmer understand what to do next.
- Welcome message and simple labels
- Add first farm and crop
- Today's task checklist
- Basic weather summary
- Beginner farming guides and AI learning videos
- Ask an expert shortcut
- Simple crop problem reporting

## Intermediate — blue theme
**Goal:** help farmers plan routine work and track operations.
- Farm and crop summaries
- Weekly task planning and recurring tasks
- Crop calendar and seasonal reminders
- Weather-aware task suggestions
- Market-price watchlist
- Expense and harvest entry
- Learning guides grouped by crop and topic

## Expert — purple theme
**Goal:** provide detailed monitoring and decision support.
- Multiple-farm operational summary
- Yield and profitability reports
- Soil and irrigation records
- Crop health history and AI-assisted issue review
- Advanced expense, harvest, and inventory summaries
- Expert question queue and evidence/photo history
- Exportable reports

## Level rules
- User selects a level during registration and can change it in profile if allowed.
- Level changes the dashboard layout, explanations, and shortcuts—not the user's ownership or security permissions.
- Backend must validate the authenticated user's role and access to each record.
