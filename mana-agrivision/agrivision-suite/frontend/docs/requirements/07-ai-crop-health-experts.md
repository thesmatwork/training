# 07. AI, Crop Health and Ask an Expert

## Crop health / disease support
- Upload crop photos where secure storage is configured
- Collect crop, location, symptoms, and duration
- Show possible causes and safe next steps with uncertainty warnings
- Encourage expert/local extension support for serious or unclear cases
- Keep a history of submitted crop issues

## AI farming assistant
- Ask questions in a clear chat interface
- Offer level-appropriate answers for Beginner, Intermediate, and Expert
- Support configurable AI providers; never expose API keys in the browser
- On failure: retry safely, show saved guides and expert help, allow provider switching when configured, enforce usage limits, log errors, and display uncertainty warnings
- AI learning videos/resources should be organised by topic and level

## Ask an Expert
- Submit text questions and crop photos
- Status: Pending, Answered, Closed
- Show answer history and timestamps
- Expert can answer assigned/allowed questions
- Admin moderation and abuse reporting where appropriate
